# Concordância Bíblica

App de estudo e busca bíblica (PWA): busca por palavra, expressão, raiz e referência; favoritos, histórico, notas e referências relacionadas; pesquisa complementar na web.

**Abrir o app:** https://rafaelximenes2010-png.github.io/concordancia-biblica/

**Instalar no iPhone:** abra o link no Safari → Compartilhar → Adicionar à Tela de Início.
**Instalar no Android:** abra no Chrome → toque em “Instalar app”.

## Dados
Os versículos são uma **amostra de demonstração** (ARC e KJV), transcrita para teste — confira em edição oficial antes de citar. Direitos da ARC pertencem à Sociedade Bíblica do Brasil.

Para trocar os dados, edite o objeto `DEMO` e a camada `Repo` em `index.html`. Ao publicar uma nova versão, altere `CACHE` em `sw.js` (ex.: `concordancia-v2`).

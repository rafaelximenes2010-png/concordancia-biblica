# concordancia-biblica
Descrição (292 caracteres):  Estude a Bíblia com uma interface inspirada em ferramentas de concordância: pesquise palavras, expressões e referências; filtre por livro e testamento; organize versículos favoritos e histórico; e amplie a investigação com buscas no Perplexity. Protótipo com amostra ARC, pronto para evoluir.
